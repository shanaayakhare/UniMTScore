Mulya = α·LEX + β·SYN + γ·SEM, on a 0 to 1 scale.

Weights

Weights are rescaled to sum to 1 within each group.

BERTScore F1 and COMET each carry a weight of 0.5 in SEM. In this page both are stand-ins unless an uploaded file supplies the real scores.

Min–max normalization bounds

X′ = (X − min) / (max − min). The BERTScore minimum is the lowest value seen in Notebook 05 (0.6127). Freeze these from your development set.

Upload a dataset

Score a whole file at once. Accepted formats: .csv, .tsv, .txt, .xlsx, .xls, .xlsm, .xlsb, .ods, .json, .jsonl. The first row must hold column names. Large files are scored in chunks so the page stays responsive. Everything runs in your browser and the file is not uploaded anywhere.

Or upload separate files: source, reference and translation in different files

Rows are matched by position. Row 1 of the source file goes with row 1 of the reference file and row 1 of the translation file, so keep all files in the same order. Accepted formats are the same as above, and a .txt file is read as one sentence per line. Reference and translation files are required. The source and human score files are optional.

Scores already computed in your notebooks (optional). Where a column is chosen, its value is used. Otherwise the page computes that part itself.
