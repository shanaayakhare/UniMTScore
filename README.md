# Unified Automatic Evaluation Framework for Machine Translation using Lexical, Syntactic, and Semantic Metrics.

# मूल्य (MuLya)
MuLya is a research prototype designed to explore machine translation evaluation through three dimensions:

- **Lexical:** BLEU, chrF++, and METEOR
- **Syntactic:** Part-of-speech and dependency-label similarity
- **Semantic:** BERTScore-inspired and COMET-inspired proxy scores

## Features
- Evaluate individual translations
- Adjust metric weights
- Score datasets using supported file formats
- Compare MuL scores with human judgments using correlation metrics
- Export evaluation results as CSV

## Running the Prototype
Open the Demo Folder and then open `index.html` in a modern web browser. An internet connection is required for the external spreadsheet library used for supported spreadsheet imports.
