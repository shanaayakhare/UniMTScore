# Notebooks

## Overview

UniMTScore is a project focused on evaluating machine-generated translations across Indian languages using a unified evaluation framework.

The project investigates multiple evaluation metrics and explores how scores from different metrics can be compared and combined to assess translation quality.

## Languages

The project covers English and six Indian languages:

- Gujarati
- Hindi
- Kannada
- Malayalam
- Marathi
- Odia

Both English-to-Indian-language and Indian-language-to-English translation directions are considered.

## Evaluation Approach

The framework investigates lexical, syntactic, and semantic evaluation metrics. Experiments compare individual metrics and explore score-combination strategies where appropriate.
