# Notebooks

## Overview

UniMTScore is a project focused on evaluating machine-generated translations across Indian languages using a unified evaluation framework.

The project investigates multiple evaluation metrics and explores how scores from different metrics can be compared and combined to assess translation quality.

## Languages

The project covers English and six Indian languages:

- Gujarati
- Hindi
- Kannada
- Malayalam
- Marathi
- Odia

Both English-to-Indian-language and Indian-language-to-English translation directions are considered.

## Datasets

The project uses the following datasets:

- FLORES-200
- IN22
- IndicMT-Eval

Dataset coverage may vary by language and evaluation task.

## Repository Structure

- `configs/` — Project configuration files
- `data/` — Dataset-related files and documentation
- `docs/` — Project documentation
- `notebooks/` — Jupyter and Google Colab notebooks
- `results/` — Evaluation outputs and experimental results
- `src/` — Reusable source code

## Evaluation Approach

The framework investigates lexical, syntactic, and semantic evaluation metrics. Experiments compare individual metrics and explore score-combination strategies where appropriate.

## Team

Developed collaboratively as an academic project.

## Status

The project is under development. Results and implementation details will be updated as experiments progress.
